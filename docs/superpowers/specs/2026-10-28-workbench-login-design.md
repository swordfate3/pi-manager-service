# 工作台登录和轻量存储

用户已批准设计后连续开发，不设置中间审批。保留一页式工作台；登录一次后在手机/电脑使用相同功能，不增加业务审批、管理码或路径限制。当前只部署本地，不修改阿里云链路。

## 选择

采用 Node 内置 SQLite + scrypt +服务端随机会话。相较外置 PostgreSQL/Redis，没有新增容器、网络或原生安装依赖；相较继续 JSON，事务能原子迁移账号/启动记录并持久保存会话。Node 最低22.19，SQLite 在该版本有实验性提示；单进程使用 DELETE journal、FULL同步，不启用 WAL。

## 边界和认证

默认全部启用认证；公开的只有登录页、认证脚本、无敏感信息的认证状态和登录提交。所有管理API、会话HTTP、文件和WS均校验数据库里的会话。HTTP Host/Origin严格匹配，HTTPS远程模式显式 publicOrigin，不信任X-Forwarded-*。本机HTTP是独立本地模式，不能通过请求头开启远程模式。

第一次本机页面设置用户名和至少12字符密码，不生成固定密码。HTTPS模式永远不提供网页初始化。CLI通过隐藏输入初始化/重置；不在命令行参数、模型对话或日志记录密码。修改密码需要当前密码，撤销全部会话；退出/全部退出/到期关闭相关WS。数据库只保存随机令牌SHA256、scrypt密码摘要和每会话CSRF。Cookie HttpOnly/SameSite=Lax；HTTPS使用Secure/__Host前缀。登录有有界节流、并发哈希上限。匿名POST也需要同源CSRF。

代理必须丢弃管理Cookie/Authorization/可信身份头，禁止下游设置管理Cookie，响应不缓存私人聊天。内部Hub仍仅回环绑定，宿主进程是受信任边界，不防同UID恶意进程。

## 数据

审查补充：反向代理后的TCP来源由多个设备共用，不能在校验正确密码之前实施15分钟封锁。登录全局最多8次/秒、并发哈希最多2个；连续失败的429只在密码不匹配后返回，正确密码可清除失败计数。WS在发起上游请求之前安装断连回收，晚到的101必须重新检查浏览器、会话和服务状态，握手最多等10秒。

state/manager.sqlite3保存单账号、有效会话、实例元数据、最近选择和有界安全事件。不保存对话正文/模型/工作区文件。runs.json验证后备份并事务导入一次；原文件保留，之后只写SQLite。数据库和备份权限0600、目录0700；错误迁移失败关闭，禁止空表覆盖损坏记录。运行状态重启核对，禁止重放启动。

## 缓存和性能

仅对已认证目录列表短期缓存(2秒/64项)，启动始终重新真实路径校验。资源ETag只针对相同静态JS；认证/HTML/API/聊天 no-store。Server-Timing提供耗时，不缓存授权结果，不把旧会话路由当在线。DB索引和清理过期会话/有界事件防无限增大。登录状态7天绝对到期，最多64活动会话(清理最旧者，只撤销登录，不限制Pi业务)。

## 验收

验证匿名HTTP/WS/文件拒绝、登录/错误密码/重复cookie、CSRF、源校验、密码修改/退出撤销、HTTPS禁止初始化、迁移/重启持久、代理隔离、缓存命中且启动重验。真实Chromium验证初始化、登录、手机布局、启动UI及退出。生产部署前检查无活跃Pi，否则只准备产物，不重启。
