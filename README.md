# Pi Manager

独立于 Pi 进程的管理服务项目：整合原 Hub 的多会话入口与 Gate 的受控执行能力，为人提供管理网页，为 Agent 提供 MCP 管理接口。

**当前状态：设计阶段，尚无可运行程序。** 本目录没有启动命令、MCP 服务或已完成的原生 Pi 启动器；不要将它当作现有 Hub/Gate 的替代部署。

## 产品边界

- 管理器先启动，随后才启动 Pi；零个 Pi 运行时也能打开管理页面。
- 管理会话、创建/停止 Pi、更新/回退 Pi，以及管理扩展安装和更新任务。
- MCP 是管理器的一种调用入口，不是管理器的生命周期宿主。调用它的 Pi 退出后，管理器和任务仍保留。
- 浏览器中的聊天由独立的 Pi Web 扩展负责。不安装管理器，也能使用单会话 Web 扩展。
- 用户管理一个产品；内部保留低权限入口与受限执行器边界，不把容器控制权限直接交给聊天扩展。

## 本轮不做的事

不停止现有 Hub/Gate，不修改阿里云、隧道、密码或真实会话，不删除旧实现，不推送远程或合并 main。只有新项目通过验收后，才另行安排部署切换。

Pi Web 的 `v1` 是 Git 分支名，不表示发布了一个新版本。当前分支仍处于拆分准备阶段，不能宣称已经完成干净 Web 包。
